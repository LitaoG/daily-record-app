## 2. 总目标

在不改变现有双模块数据、统计、登录或同步语义的前提下，统一改版以下三个核心页面：

- 日历页：使用轻微圆角方形日期热力单元，减少汉字和常驻边框。
- 日期记录页：点击日历日期后进入；次数是唯一主焦点，保存是唯一主操作。
- 统计页：月统计使用紧凑三项摘要、逐日次数脉冲图、次数分布和单日极值；年统计使用单张 12 个月折线面积分析。

产品仍只记录两个固定且独立的模块：

- 自慰。
- 做爱。

本轮不新增时间、感受、备注、伴侣、地点、时长、图片、医疗信息、目标、连续天数、提醒或其他记录类型。

## 3. 已确认的视觉基线

### 3.1 共用视觉语言

- Canvas 使用接近白色的暖中性色，不使用明显发黄的纸张纹理。
- 正文使用石墨色；减少纯黑、大面积粗体、阴影、厚描边和卡片套卡片。
- 两个模块共用页面结构、排版、间距、圆角、底部导航、错误色与成功色。
- 模块色只用于当前模块身份、热力强度、焦点、主按钮和选中状态；不能成为唯一的状态说明。
- 以下颜色是已确认的实现起点。允许为 WCAG 对比度做小幅明度调整，但不得更换已确认的紫色/深红色相方向；调整必须记录在阶段 1 PR 中。

| 角色 | 基线值 |
|---|---|
| Canvas | `#FAF8F3` |
| Surface | `#FFFEFB` |
| Primary text | `#2D2926` |
| Subtle line | `#D8D0C6` |
| 自慰主色 | `#85569A` |
| 自慰深色 | `#603670` |
| 做爱主色 | `#A54658` |
| 做爱深色 | `#7A3040` |

### 3.2 模块切换器

- 单层外框严格二等分；左右模块各占完整宽度的一半和完整高度。
- 选中颜色必须覆盖对应半区直至外框边界，不允许恢复内部小胶囊。
- 文字与图标居中，选中视觉范围、语义范围和点击范围一致。
- 自慰使用紫色系和飞机符号；做爱使用深红色系和非露骨双环符号。

### 3.3 日历页

- 日期使用统一的方形或轻微圆角方形数据单元，不使用圆形日期点。
- 过去未填写只显示日期并使用浅中性底，不显示“未填”汉字；TalkBack 仍明确“未填写”。
- 明确 0 与未填写不同，使用空心标记或独立边框；保存 0 不等于清除。
- 1、2、3 次以上使用当前模块同色系整格背景逐级加深，同时保留精确次数或稳定标记。
- 今天保留“今”或今天边界；未填写的今天仍保持浅色。
- 未来日期使用区别于过去未填写的独立禁用浅色，只淡化和禁用，不在日期格内显示“未来”汉字。
- 日历首页月摘要只显示“本月总次数 · 发生天数”，记录日均留在统计页。
- 短月份在底部导航上方使用轻分隔、点击提示和集中四态图例收尾；不增加说明卡或新功能。
- 点击日期进入日期记录页；日历格内不提供加减控件。
- 月份切换、年月快速跳转、浏览日期和模块切换行为保持不变。

### 3.4 日期记录页

- 从日历日期进入，不成为第三个底部导航入口。
- 顶部明确日期和当前模块；次数数字是唯一主焦点。
- `-1`、`+1` 点击目标至少 48dp；次数下限仍为 0。
- 保存是唯一主按钮；清除是次级文字操作，已有确认逻辑保持不变。
- 只显示一套当前记录状态和一行低权重月度上下文，不堆叠解释卡。
- 不显示时间、感受、文本框或其他尚未立项字段。

### 3.5 统计页

- 周、月、年、全部继续使用同一浏览日期和现有统计口径。
- 周、年和全部仍以总次数为主指标；月统计按用户最终选择使用紧凑三项摘要，同时展示总次数、发生天数和记录日均。
- 0 次图形为真正零高度；未填写不伪装成 0；未来不预测。
- 月统计按当前 `YearMonth` 生成完整逐日序列，使用无连线脉冲图表达具体日期与次数；次数标签贴近节点，横轴在 1、5、10、15、20、25 和月末日期处用当前模块色圆环高亮基线锚点。再以已填写日期为分母展示 `0 / 1 / 2 / 3 次以上` 次数分布，并列出最高单日和最低单日次数（最低单日仅统计正次数）。不按周汇总，不重复日历页真实日期网格；过去未填写、明确 0、正次数和未来日期保持独立语义。
- 年统计不使用 53×7 的逐日热力图，避免手机端过密；主图固定为单张 12 个月直线折线面积图，相邻有效月份直接用直线连接，每月显示轴标签，已记录点上方显示精确次数。
- 明确 0 次使用基线实心点；未填写和未来月份使用空心位置标记、不参与连线，也不制造预测。年统计另外提供季度次数占比圆环、月均次数、最高月份和最低月份；不再同时堆叠表达相同趋势的柱状图。
- 当前年份的未来月份为空，进行中的当前月可以显示但不进入最高/最低排名；过去年份使用全部 12 个月。
- 最高/最低月份只在至少存在一条已保存记录的完整月份中计算，未填写月份不伪装成 0；明确保存 0 的月份可以合法成为最低月份。
- 最高/最低出现并列时完整列出并列月份；没有合格月份时显示明确空状态。
- 季度圆环只计算正次数占比，总次数为 0 时显示空状态，不制造占比。
- 自慰和做爱分别读取自己的逐日数据，绝不混合。

### 周统计“未到”与“1次”颜色区分修正（2026-08-12）

用户真机反馈周环图“未到”与“1次”看起来过于接近，因此通过新的 [Issue #180](https://github.com/LitaoG/daily-record-app/issues/180) 定向维护，不重新开启已关闭的 UI v2 阶段。当前规则固定为：自慰与做爱模块中，`1 / 2 / 3 / 4次及以上` 逐档复用主页对应次数块色，“0次”保持现状；“未到”复用主页未来日期块的 `Disabled` 背景色，周几日期文字继续使用暗淡的未来字色。未来环段继续更细并保留文字和 TalkBack 状态语义。该修正不改变统计口径、日期范围或其他次数色阶。

### 周统计未填色与周三/周六间距修正（2026-08-13）

最新真机反馈指出，周环图“未到”不能使用统一灰米色，而应复用主页对应模块“未填”日期块的 `Unset` 背景色；周几文字继续保持未来态暗淡色。另将周三、周六标签相对环圈的径向间距增加 6dp。该定向维护由 [Issue #195](https://github.com/LitaoG/daily-record-app/issues/195) 记录，不改变统计口径或其他周期图表。
