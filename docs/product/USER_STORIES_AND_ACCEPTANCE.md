# 用户故事与验收

## US-01 快速记录

作为用户，我希望选择自慰或做爱模块与日期后快速调整次数，以便记录不打断当天节奏。

- `+1` 调整次数后点击保存，完成本地持久化。
- 同一模块同日再次保存只更新同一条记录；另一模块不受影响。
- 日历和统计立即刷新。

## US-02 明确 0 次

作为用户，我希望把某模块某天记为 0 次，以区别于忘记记录。

- 0 次在数据库中保留一行。
- 日历显示“没冲”状态，不能与空白未填写相同。
- 统计明细显示 0，但次数和对应发生天数不增加；柱状高度为 0。

## US-03 修正记录

作为用户，我希望修改历史日期或清除误记录。

- 支持 `-1` 与 `+1` 调整非负整数。
- 次数不会低于 0。
- 清除后该日期恢复未填写。

## US-04 回看统计

作为用户，我希望按周、月、年和全部历史查看当前模块次数与天数。

- 汇总、表格和日期明细使用同一范围。
- 当前周期标注进行中。
- 未来数据不预测。
- 自慰统计不读取做爱数据，做爱统计不读取自慰数据。

## US-05 模块切换

作为用户，我希望在自慰和做爱之间切换，同时保留当前日期与统计上下文。

- 模块入口始终使用文字和非露骨图标，不只依赖颜色。
- 切换模块保留浏览年月、选中日期和周/月/年/全部周期。
- 应用重启后恢复上次选择的模块。
- 同一天两类记录可同时存在；保存、清除或同步其中一个不会覆盖另一个。

## US-06 离线可靠

作为用户，我希望没有网络也能记录和查看。

- 飞行模式完成所有核心任务。
- 重启应用后数据仍存在。
- 应用不要求登录。

## US-07 快速回看历史

作为用户，我希望直接选择年份和日期，不需要连续点击月份箭头。

- 点击日历年月或统计周期标题打开应用内日期选择器。
- 可选择 1970 年 1 月 1 日至今天，不允许进入未来。
- 日历与周/月/年统计共享浏览日期，切换页面和周期不擅自回到今天。

## US-08 可选换机恢复

作为用户，我希望在需要时登录账号，并在另一台手机恢复记录。

- 未登录时所有核心功能仍可使用。
- 首次登录先把两个模块的本机记录迁入各自账号空间，再尝试访问云端。
- 网络失败时记录继续保留在 Room；恢复后自动上传。
- 不同 Firebase UID 不能读取或修改彼此记录。

## US-09 找回密码

作为用户，我希望忘记密码后通过注册邮箱重置，再返回应用登录。

- 登录页提供找回密码入口并预填已输入邮箱。
- 请求超过约 5 秒停止等待；网络错误提供 VPN/网络操作提示。
- 无论邮箱是否已注册都显示同一成功提示，避免泄露账号存在性。
- 应用不读取、生成或保存用户的新密码。

## US-10 理解并处理同步问题

作为用户，我希望知道记录是否已同步，以及失败后该做什么。

- 账号入口区分已同步、同步中、待同步、离线和失败。
- 网络、认证、权限、配额、服务、数据和未知错误显示不同操作建议。
- 只有网络类错误提示检查 VPN；所有错误都明确本机记录仍可使用。

## US-11 删除账号与云端数据

作为用户，我希望永久删除账号和本人云端记录，并决定是否保留本机记录。

- 删除经过不可撤销警告、数据选择和当前密码重验。
- 默认保留本机记录为离线数据；同时删除本机记录必须主动选择。
- 先删除本人自慰和做爱 Firestore 文档，再删除 Firebase Authentication 账号。
- 任何失败都不误报成功，并保留可重试状态。
