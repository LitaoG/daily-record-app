# Daily Record 明亮渐变玻璃主题

状态：`implemented — archived baseline for v1.0.0-beta.2`

最后复核：2026-08-08

本轮是一次纯视觉材质迁移：保留当前日历、统计、记录、账号和弹窗的布局、尺寸、文案、信息层级、点击范围、状态语义与业务逻辑，只统一背景、表面、渐变、高光、描边和阴影。

## 视觉契约

- 页面保持暖白底，环境色只使用极低透明度的当前模块色，不制造暗角。
- 普通表面使用明亮乳白玻璃、极细亮边和低阴影；不使用厚重黑色阴影或脏灰紫渐变。
- 周/月/年/全部继续使用等宽玻璃胶囊和内缩悬浮滑块；滑块几何与点击逻辑不变。
- 模块选择器继续是单层、严格二等分、整半区点击；它的选中半区仍保持清晰的模块身份色。
- 日历状态格和图表数据绘制不套用强玻璃，以免削弱未填写、明确 0、正次数和未来的可辨识度。
- 自慰使用明亮纯净紫色，做爱使用明亮克制酒红色；所有共享表面通过当前模块令牌取色。

## 实施顺序

1. 建立共享玻璃令牌与 modifier，不改变调用方测量。
2. 迁移页面背景、顶栏、模块选择器外围、周期选择器和底部导航。
3. 迁移统计卡、记录编辑面板、按钮、空状态和图表容器。
4. 迁移日期/年月、账号、密码重置、确认弹窗和反馈条。
5. 分别检查自慰紫色、做爱酒红色、未选中、禁用、错误和空状态。
6. 在最终功能 head 上做一次完整验证、模拟器截图回归和公共仓库 PR/CI。

## 非目标

本轮不修改数据库、同步、认证、统计计算、导航、日期规则、图表类型、运行时文案、布局结构或任何新功能；不发布新版本，也不在每个小改动后同步私有恢复仓库。

- 共享玻璃材质集中在 `ui/theme/Glass.kt`；调用方只叠加 modifier，未改变现有测量、状态或语义。
