# 设置中心 Goal

状态：`implemented and verified`

来源：2026-08-09 用户直接需求。

## 目标

在不改变“日历 / 统计”双主导航和本地优先数据边界的前提下，为主页增加一个设置入口，把低频的账号、记录偏好、隐私与应用信息集中到独立页面。

## 首版范围

- 主页顶部提供至少 48dp 的设置按钮，TalkBack 读作“打开设置”。
- 设置使用全屏次级页面；顶部返回和系统返回都回到原主页，不新增第三个底部导航。
- “账号与同步”展示本机或已登录状态。本机模式可继续进入登录；已登录状态复用现有账号管理弹窗。
- “记录偏好”允许切换手冲 / 做爱；沿用已有 `SelectedRecordModulePreference`，选择后立即生效并持久化。
- “数据与隐私”只陈述已经成立的本机优先、未登录不上传、无广告、无分析或崩溃上报 SDK 边界。
- “关于”显示当前版本号和 Apache 2.0 许可。
- 页面沿用暖白 Canvas、轻玻璃 Surface、现有排版间距与当前模块配色；支持窄屏、滚动、200% 字体和 TalkBack。

## 明确不做

- 不增加深色主题、提醒、目标、连续打卡、自定义活动或周起始日设置。
- 不增加尚无真实行为的数据导出、应用锁、备份开关或占位入口。
- 不修改 Room schema、Firestore、记录实体、统计口径、同步协议或账号删除语义。

## 验收

- 本机与已登录主页都能进入设置，并能可靠返回原页面。
- 设置页在无账号时提供登录同步入口；有账号时能打开现有账号管理。
- 在设置页切换记录模块后，主页内容与配色同步切换，重组后仍保留选择。
- 正常字号与 200% 字体下，全部内容可滚动到达，关键点击目标不小于 48dp。
- Kotlin、AndroidTest 编译和相关 Compose 设备测试通过；模拟器截图与 Crash Buffer 无阻断问题。
