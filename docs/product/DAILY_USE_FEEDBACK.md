# 日常使用反馈

本项目面向本人和少量朋友使用，不组织固定人数的正式可用性测试，也不以完成率、操作时长或问卷分数作为发布门槛。

## 反馈范围

- 日历无法打开、回退桌面、卡死或明显性能异常。
- 记录新增、修改、显式 0 次或清除后出现错误、丢失或重复。
- 周、月、年和全部历史统计与日历记录不一致。
- 离线记录、重新联网、换机恢复或账号隔离异常。
- 文案、弹窗、字体放大或 TalkBack 导致核心操作无法完成。

## 反馈方式

发现问题时记录应用版本、手机型号、Android 版本、网络环境、发生时间、操作步骤、预期结果、实际结果和可选截图。不要附带密码、完整邮箱、真实自慰日期或次数等隐私数据。

确认可复现的问题进入 GitHub Issue 或下一次修复分支；无法稳定复现的问题先保留操作步骤和可选截图，待再次出现后补充。自动化测试、升级兼容、账号隔离、离线写入和云端恢复仍是合并与发布的硬门禁。
