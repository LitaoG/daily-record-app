# 记录时间与感受：确认稿

Issue：[#105](https://github.com/LitaoG/daily-record-app/issues/105)

这组设计资产对应记录页的两个连续状态：

1. 计数为 0 时不显示入口；计数为 1 次及以上时，在“已记录 · N 次”下方显示“记录时间和感受”按钮。
2. 点击入口后展开“本次详情”，为每一次记录提供可选的开始时间、结束时间和 100 个可见字符以内的感受。

## UI 规则

- 自慰和做爱模块共用这套交互结构，但数据模型、Room 表、Repository 和云端集合保持独立。
- 计数仍是主任务；时间和感受只在计数大于 0 且用户主动点击入口后渐进展开。
- 详情全部可选，保存次数不能被空详情阻塞。
- 开始/结束时间成对填写时，结束时间不得早于开始时间。
- 感受文本按可见字符计数，中文、标点和 emoji 各计 1 个，最多 100 个；不写入日志或诊断信息。
- 聚合次数不受详情编辑器的行数上限影响；为避免异常大次数触发内存分配，详情编辑器最多物化 512 行，超出时仍可保存总次数，已有详情不会因次数保存被清空。
- “清除记录”仍清除当天模块记录，同时清除对应的逐次详情；不影响另一个模块。
