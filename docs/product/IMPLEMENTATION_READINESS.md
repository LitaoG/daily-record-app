## 已冻结

- 固定对象：自慰、做爱两个独立模块。
- 每个模块每个日期最多一条记录；同一天可同时存在两类记录。
- 次数为非负整数；0 表示当天没有发生该行为但用户已填写；无记录表示未填写。
- 主导航仅日历与统计。
- 统计周期：周、月、年、全部历史。
- 指标：当前模块总次数、发生天数、记录日均。
- 本地 Room 是唯一 UI 事实来源；邮箱密码账号和云同步可选。
- 登录后本机数据合并到账号；新设备可恢复，普通登录无短信验证码。
