## 为什么再次调整

主页日历已经负责回答“哪一天是什么状态”，旧月统计的日期网格会重复主页；随后尝试的
5/6 个周桶又把一个自然月切成并不稳定的周段，用户仍然难以直接看出具体哪天发生、
次数主要由什么强度构成，以及单日最高/最低是多少。

用户最终选择“次数分布”方案的完整信息结构，并加入“每日次数”脉冲图。月统计现在回答：

1. 哪些具体日期有正次数、次数是多少。
2. 已填写日期中，0、1、2、3 次以上各占多少天。
3. 单日最高与最低次数是多少（最低单日仅统计正次数）。

## 当前交付

月份导航、进行中/已结束状态和模块隔离保持不变。页面按以下顺序展示：

1. **紧凑摘要**：本月总次数、发生天数、记录日均。
2. **每日次数图**：横轴覆盖当月全部真实日期，正次数使用细竖线、节点和精确数值；不连接相邻日期。
3. **次数分布**：只以已填写日期为分母，分为 `0 次 / 1 次 / 2 次 / 3 次以上` 四档；未填写和未来日期在分母外单独列出。
4. **单日极值**：最高单日和最低单日次数；只显示次数，不展开日期列表，最低单日仅统计正次数。

### 状态语义

- 正次数：绘制真实高度的竖线、节点和次数标签。
- 明确 0 次：保留当前模块色的基线实心点，不绘制假高度。
- 过去未填写：使用中性空心基线点，不伪装成 0。
- 未来日期：使用更淡的禁用空心点，不预测。
- 最低单日只统计正次数；明确 0、未填写和未来日期均不参与。
- 最高/最低没有正次数时显示明确空状态。

### 视觉规则

- 自慰使用紫色系，做爱使用深红色系；组件结构与中性色完全一致。
- 每日图固定显示当月真实日数，横轴只标出 `1、5、10、15、20、25、月末`，减少拥挤。
- 次数分布使用同一模块色根的四档明度，不使用彩虹配色。
- 卡片保持暖白 Surface、细分隔线和克制圆角，不增加卡片套卡片或厚重阴影。
- 正常字号下保持紧凑；200% 字体下摘要改为纵向排列，文案不得截断。

## 明确不做

- 不按周汇总，不展示活跃周、峰值周或第 1–6 周柱。
- 不重复主页月历日期格，不使用月度热力图。
- 不新增连续天数、目标、预测、时间、感受、备注或其他业务字段。
- 不修改周、年、全部历史、登录、同步、Room 或 Firestore。
- 不引入第三方图表依赖；图形继续使用现有 Compose 能力绘制。

## 验收矩阵

| 场景 | 预期 |
|---|---|
| 空历史月 | 全部日期为空心未填写点；已填写 0 天；极值为空状态 |
| 明确 0 次 | 基线实心点；计入“0 次”分布和已填写天数；不增加发生天数，不参与最低单日 |
| 正次数 | 竖线高度和标签使用精确次数；计入对应构成档和极值 |
| 过去未填写 | 中性空心基线点；计入未填写，不进入构成分母 |
| 未来日期 | 淡化空心基线点；单独统计未来天数，不预测 |
| 并列极值 | 只显示该极值次数，不展开并列日期 |
| 闰年二月 | 横轴和模型包含 29 个真实日期 |
| 28/29/30/31 天月份 | 月末横轴标签和日期点与真实月长一致 |
| 切换月份 | 日序列、构成和极值整体重算，不保留上月结果 |
| 双模块 | 当前模块统计不读取另一个模块记录；全部色阶跟随当前模块 |
