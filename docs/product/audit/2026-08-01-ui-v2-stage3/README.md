# 2026-08-01 UI v2 Stage 3 记录页定向验收

状态：`Historical — implementation carried forward into v1.0.0-beta.3`

当时状态（2026-08-01）：`Implementation verified — awaiting user acceptance`。本页保留记录页阶段的截图和测试范围，不表示当前阶段仍未关闭。

范围：只改造点击日期后的次数记录页；不提前加入时间、感受、文本框或新的数据字段，也不改变 Room、同步、登录和统计业务规则。

## 本阶段实现

- 顶部明确显示日期、星期、今天/历史日期/未来日期，并保留返回日历入口。
- 自慰和做爱共用同一套记录页结构，分别使用紫色和深红色模块色；数据控制器与领域模型仍完全独立。
- 次数是唯一主焦点：`- / 当前次数 / +` 使用不小于 48dp 的触控目标，0 次仍可明确保存。
- 页面只保留一个状态摘要：加载中、未来不可记录、尚未填写、待保存或已记录；移除控件内重复的“尚未保存”。
- 保存是唯一实心主按钮；清除记录改为低权重文字操作，仍需要二次确认。
- 月度上下文只显示已保存次数与发生天数，明确区分已保存数据和当前未保存草稿。
- 保留加载禁用、快速点击保护、保存/清除失败、返回确认、生命周期和远端更新行为。
- 记录页顶部容器按内容自适应，200% 字体下不会裁掉“今天/历史日期”副标题。
