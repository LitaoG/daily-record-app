# 2026-08-02 统计周期玻璃分段控件

本次只替换统计页顶部“周 / 月 / 年 / 全部”的视觉表达，不改变统计周期、浏览日期、数据口径或无障碍语义。

## 实现结论

- 外层为自适应宽度的完整胶囊，使用半透明乳白和当前模块淡色阶渐变，配合低透明描边与轻阴影。
- 四个入口等宽；当前项由独立的白色玻璃滑块表示，按共享 Compact 间距在每段左右和上下内缩，保留均匀悬浮留白而不贴边。
- 滑块带非常轻的顶部高光、当前模块主色的低透明环境辉光和 2dp 柔和阴影；自慰使用紫色，做爱使用深红色；没有底部下划线、图标或高饱和整块填充。
- 分段点击不使用默认矩形 ripple；点击反馈由滑块的弹性移动和文字颜色过渡承担，避免胶囊控件出现突兀的长方形变色。
- 选中项颜色跟随当前记录模块深色阶（自慰为深紫，做爱为深红），未选项使用通过 WCAG AA 检查的低饱和蓝灰色。
- 点击仍保持 `Role.Tab`、`selected` 语义、稳定 `statistics_period_*` 测试标签和至少 48dp 触控高度；滑块使用 spring 平滑移动，文字颜色使用短时过渡。
