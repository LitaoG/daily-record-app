## 本轮修正

常规字号下将顶部两个文字操作的水平间距从 4dp 调整为 12dp。大字号布局原本使用
两端对齐，不受影响。

![顶部操作修正后](06-calendar-after-spacing.png)

修正后两个入口能被直接识别为独立操作。连续三次模拟器冷启动的 Activity
`TotalTime` 为 2562ms、2210ms 和 1835ms；安装 APK 后的首次启动还会受到系统
安装优化影响，不将该次启动用作常规性能结论。
