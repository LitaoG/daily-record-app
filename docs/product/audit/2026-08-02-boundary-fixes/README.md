# 2026-08-02 统计与日历边界修复

本次修复只处理已确认的交互和边界问题，不改变整体视觉方向，也不新增业务字段。

## 变更范围

- 统计页的 `周 / 月 / 年 / 全部` 周期切换改为普通低圆角矩形白色容器；四个入口等宽且保持至少 48dp 点击区域，当前周期只用当前记录模块色的文字和下划线表示。
- 月统计继续使用按所选月份重新计算的 5/6 个周聚合柱，不复刻主页日历日期格；0 次、未填写和未来周保持不同语义，切换月份不会残留上一月数据。
- 年度极值的月份列表独占一行，避免窄屏或大字体把 12 月、并列月份挤出；月份只有在完整结束后才参与极值排名，12 月 31 日仍属于进行中，次年 1 月 1 日起可排名。
- 主页日历将过去未填写与未来/不可用日期使用不同的中性底色，并维持可读对比度和 TalkBack 语义。
- 年月日期跳转弹窗的选中态、摘要和操作按钮跟随当前模块颜色；手冲使用紫色，做爱使用深红色，不改变日期范围和跳转规则。

## 验收与回归

- `StatisticsModelsTest` 新增跨年后 12 月最高/最低、当前 12 月排除、并列极值保留 12 月三个用例。
- `DesignTokensTest` 继续验证未来与过去未填写底色不同，并验证未来状态前景达到可读对比度。
- 周期切换和日期跳转继续沿用现有 Compose 语义、测试标签与 48dp 点击区域契约。
- 本次代码验证按 [`docs/TESTING.md`](../../../TESTING.md) 的增量规则执行；完整设备回归仍只在小版本冻结时执行。

## 明确不变

本次不改变数据库、同步、登录、记录编辑流程、月统计的数据口径或年度图表依赖。后续若扩展记录模块，周期和跳转组件继续从 `RecordModuleColorTokens` 注入颜色，统计仍只消费当前模块的数据集。
