# 界面与交互

最后复核：2026-08-15

> 本文描述当前 Compose 运行时已经实现的交互。UI v2 Stage 0 至 Stage 6 已完成并发布 `v1.0.0-beta.3`；阶段截图是历史证据，后续变化必须通过新的 Issue/PR 更新本文。最终发布审计见[Stage 5/6 记录](product/audit/2026-08-03-stage5-stage6-release/README.md)，发布后的无障碍修复见 PR #90。

视觉基线：接近白色的暖中性 Canvas、白色 Surface 和石墨文字。自慰使用克制紫色与飞机符号，做爱使用克制深红与非露骨双环符号；两个模块始终同时显示清晰文字，不能只依赖颜色或图标。

## 文案原则

- 用户可见文案只保留完成当前操作所需的信息；标题不重复正文，说明不复述用户已经能从界面直接看出的事实。
- 统计页使用“发生天数”和“日均次数”等直接说法；“未填写、0 次、未来”分别表示不同状态，不用绕口的技术术语代替。
- 需要解释统计口径时只说明排除条件，例如“0 次和未填写不参与统计”；其余规则放在文档和无障碍语义中，不堆在卡片上。
- 所有运行时文案集中在 `AppCopy.kt`，新增文字先复用已有词汇，再补充最短、可行动的一句提示。

## 导航

底部仅两个入口：

1. 日历
2. 统计

设置不作为第三个底部入口；主页顶部的 48dp 设置按钮进入全屏次级页面，顶部返回和系统返回都回到原页面。设置只承载已经真实存在的低频能力，不展示空开关或“即将推出”占位项。

选中入口只使用当前模块色图标、文字和下划线，不使用大面积实心胶囊；整个入口保持至少 48dp 的点击与 TalkBack 范围。

## 设置中心

- 信息顺序为“账号与同步 → 数据与隐私 → 关于”，先放账号操作，再放解释性信息。
- 本机模式显示“本机记录”和登录同步主操作；已登录时显示邮箱与同步状态，点击后复用现有账号管理弹窗。
- 自慰 / 做爱模块切换只保留在主页，避免在设置页重复提供相同操作。
- 数据与隐私只说明已经成立的本机优先、未登录不上传、无广告、无分析或崩溃上报 SDK 边界；不伪造导出、备份、应用锁或权限管理能力。
- 关于区域显示运行中的版本号和 Apache 2.0 许可。
- 页面使用可滚动列表，在窄屏和 200% 字体下可自然滚动；设置、返回、账号和模块控件都有明确 TalkBack 文案与至少 48dp 点击范围。

## 共享外壳

- 日历和统计使用同一组 20dp 页面水平边距、排版、分隔线和底部导航。
- “自慰 / 做爱”切换器为单层外框并严格二等分；两个模块各占完整宽度一半和完整高度。
- 选中颜色覆盖对应半区直至外框边界，不存在内部小胶囊；颜色范围、点击范围和语义范围一致。
- 自慰选中使用明亮紫色 `#8A5AA7`，做爱选中使用清晰酒红 `#AD485C`；白色文字对两者均达到 WCAG AA。普通表面遵循[明亮渐变玻璃主题契约](product/BRIGHT_GLASS_THEME.md)。
- 统计周期使用四段式玻璃胶囊：外层为半透明乳白渐变和柔和描边，当前项由带留白的悬浮白色滑块表示；不使用底部下划线或高饱和整块按钮。
- 正常字号和 200% 字体下，模块切换、周期标签和底部导航均保持可读，点击目标不小于 48dp。

## 日历页

- 日历与统计顶部提供“自慰 / 做爱”模块切换；切换保留浏览日期，重启恢复上次选择。
- 顶部显示年月、上一月、下一月、回到今天；年月标题本身是可点击的 48dp 入口，打开年份与日期选择器。
- 可浏览范围为 1970 年 1 月至当前月；到达边界后对应月份箭头禁用。
- 快速跳转使用应用内原生暖色实体弹窗，不调用系统日期选择器：直接用年 / 月 / 日三列滚轮调整日期，不再重复主页月历网格。
- 日期选择器禁止 1970 年以前和今天以后日期；切月会把选中日夹紧到目标月的合法日号，确认后只移动浏览焦点，不误打开记录编辑页。
- 快速跳转和账号同步共用应用内暖中性实体 Surface、应用级紫色主按钮与 48dp 点击目标；弹窗状态用标题、文案和形状共同表达，不只依赖颜色。
- 年月下方使用紧凑文字摘要，只显示“本月总次数 · 发生天数”；日均次数留在统计页，不再使用大面积摘要胶囊。
- 当前月日期由真实 `YearMonth` 生成并按周一至周日排列，只补空位、不显示相邻月份日期；五周月和六周月按真实行数展开。
- 日期格同时表达今天、选中状态和记录状态。
- 过去未填写：使用当前模块的极浅色系整格背景（自慰为浅紫，做爱为浅酒红），不显示“未填”汉字，并提供“未填写”的 TalkBack 文案。
- 明确 0 次：使用白底、当前模块主色描边和空心圆，不显示 `0 次` 汉字，并提供“当前模块，记录为 0 次”的 TalkBack 文案。
- 1、2、3、4 次以上：使用当前模块同色系由浅到深的四档整格背景，并显示精确次数；极端值显示为“9 次以上”，详情仍显示真实值。
- 今天使用当前模块色边界；今天未填写时只额外显示“今”，已经保存记录时保留次数文字并由边界表达今天。
- 未来日期使用比过去未填写更浅的独立禁用中性色，并禁止点击和保存；日期格内不显示“未来”汉字，TalkBack 仍明确未来且不可记录。
- 短月份在底部导航上方使用轻分隔线、“点击日期填写次数”和集中四态图例收尾；六周月和大字体超出可用高度时自然滚动。图例不是按钮，也不改变点击日期进入记录页的行为。

## 日期记录面板

- 标题为完整日期和“今天/过去日期”辅助说明。
- 中心突出当前次数。
- `-1` 与 `+1` 为主要快捷操作，次数下限为 0。
- 保存 0 次表示当天没有发生该模块行为；“清除记录”只让当前模块恢复未填写。
- 详情展开时，“清除记录”只清除当天每次记录的时间和感受，保留次数并停留在当前记录页，行为与保存一致；详情收起时才清除当前模块的整条记录并返回日历。
- 保存或整条记录清除后同步更新日历与统计；详情清除只更新详情，不改变统计。
- 数据库记录尚未读取完成时，次数控件和保存按钮保持禁用，避免把旧记录误覆盖为 0。
- 保存和清除开始前同步锁定操作，快速连点只执行一次；失败时留在当前页面、恢复按钮并显示重试提示。
- 清除记录需要二次确认；修改次数后返回需要确认是否放弃，防止误触造成数据丢失。
- 清除与放弃确认统一使用应用内 Surface 弹窗，不调用 Material 默认 `AlertDialog`；危险操作使用深红实心按钮，取消/继续编辑使用应用级紫色描边按钮。
- 保存或清除失败使用应用内当前模块深色 Snackbar：自慰使用紫色深色阶，做爱使用深红色深色阶，并保留明确文字和 TalkBack 实时提示。

## 统计页

- 顶部周期分段：周、月、年、全部历史；四项等宽并保持至少 48dp 触控高度。外层使用自适应高度的轻玻璃拟态胶囊，当前滑块按分区宽度动态计算并保留内缩留白，平滑移动并跟随当前模块色阶，选中文字使用当前模块深色阶，未选文字使用低饱和蓝灰色；不显示默认矩形 ripple。
- 周、月、年提供上一周期、下一周期和标题日期选择器；当前周期不允许继续进入未来。
- 日历与统计共用浏览日期。切换统计周期只改变聚合范围，不重置日期：例如浏览 2026 年 5 月 6 日时，周显示 5 月 4–10 日，月显示 5 月，年显示 2026 年。
- 第一屏固定一个当前模块主指标“总次数”，并在同一张摘要卡中显示发生天数和日均次数；不使用三张等权 KPI 卡。
- 月周期下方依次显示逐日次数脉冲图、按已填写日计算的 `0 / 1 / 2 / 3 次以上` 次数分布，以及最高单日和最低单日（最低单日仅统计正次数）；脉冲图的次数标签贴近节点，横轴在 1、5、10、15、20、25 和月末日期处用当前模块色圆环高亮基线锚点，方便对应日期；不按周汇总，也不重复主页日期网格。年周期下方显示单张 12 个月折线面积图、季度次数占比和最高/最低月份摘要；全部历史仍以事实列表为主。
- 下方图表和列表只展示已发生事实：0 次不绘制假柱，未填写不伪装成 0，未来月份不预测。
- 进行中的周期明确标注；未来日期/月不预测。
- 全部历史为空时提供“去日历填写”按钮；统计明细当前只读，不伪装成可点击入口。

## 登录与找回密码

- “忘记密码？”只在登录模式出现，使用登录页已输入邮箱作为预填值；注册模式不显示该入口。
- 登录模式显示“登录后可恢复云端记录”，并提示需使用 VPN 登录；注册模式显示“注册后可保存数据到云端方便长久记录”，并提示需使用 VPN 注册。两种模式都引导无 VPN 时使用“本机记录”。
- 找回密码使用暖中性 Surface、应用级紫色描边和应用内弹窗，不使用系统默认确认框。
- 邮箱无效时在输入框内给出文字错误；发送期间锁定输入、取消和发送按钮，避免重复请求。
- 成功状态统一显示“如果该邮箱已注册”，不暴露账号是否存在；同时提醒检查收件箱和垃圾邮件。
- 断网、限频、额度耗尽和其他失败均留在弹窗内并允许重试，不显示 Firebase 内部错误文本。
- 密码重置遇到网络失败时直接提示打开 VPN 后重试。
- 系统字体 200% 时操作纵向排列，标题、说明、输入框和两个操作均保持可见；重置邮件打开的浏览器/邮件客户端属于系统边界。

## 账号删除

- “删除账号与云端数据”位于账号弹窗底部，使用危险文字层级，不与“退出登录”混淆。
- 第一层弹窗说明不可撤销，并要求选择本机记录处理方式；“保留本机记录（推荐）”默认选中，“同时删除本机记录”必须主动选择。
- 第二层弹窗说明实际影响并要求当前密码；密码为空时永久删除按钮不可用。
- 删除期间锁定关闭、返回、输入和提交，避免重复请求；失败原因留在弹窗内，密码错误、网络/VPN、限频和登录状态变化使用不同文案。
- 所有警告、选择卡、密码框和危险按钮使用应用内纸感组件；只有软键盘属于系统 UI。

## 无障碍

- 颜色不是唯一状态表达；同时使用数字、形状和文本。
- 云同步因网络失败时显示数秒的应用内当前模块色 Snackbar，自慰使用紫色、做爱使用深红色，明确提示打开 VPN，并说明记录仍已保存在本机；非网络类失败不显示 VPN 提示。
- “账号与云同步”弹窗打开时，网络类 VPN 提示必须移入弹窗内的同步状态卡，根页面 Snackbar 立即消失，避免被模态遮罩压在下层或重复显示。
- 点击目标至少 48dp。
- 支持 TalkBack、系统字体缩放与高对比检查。
- 200% 字体下月份标题改为两行，日期格增高，统计指标卡改为纵向排列，避免文字截断。
- 周/月分布图必须直接标注状态并提供完整 TalkBack 语义；月统计读出每天的未填写、0、正次数或未来状态，并汇总构成与极值次数，年图提供 12 个月、季度和极值摘要的可访问语义。

## 加载、保存与视觉对比度

- 本机数据库首次读取期间只显示明确加载状态，不提前显示假的“0 次 · 0 天”或空日历。
- 已有记录未发生变化时主按钮显示“已保存”并保持禁用；只有次数变化后才变为可操作的“保存记录”，避免无意义写入和云端修订。
- 日历年月与统计周期标题保持整块可点击和 TalkBack 跳转语义，但不显示重复的“点此快速跳转”副标题。
- 自慰主色 `#8A5AA7`、做爱主色 `#AD485C` 以及正文与玻璃表面之间的对比度由 `DesignTokensTest` 验证达到 WCAG AA；日期状态仍同时使用数字、边框和文案，不只依赖颜色。
- 月历只渲染当前月份的日期；前后月份对应位置留白、不可点击且不进入 TalkBack 焦点。相邻月份通过左右箭头或年月快速跳转进入。
- 周统计使用七日纵向分布卡，直接标注每天次数、日号以及未填写/未来状态；月统计使用完整逐日脉冲图、按已填写日计算的次数分布和单日极值，不再重复主页日期网格；未填写、0、正次数和未来均有不同语义。
- 周/月/年顶部采用单一主摘要卡突出当前模块周期总次数，并并列展示发生天数和日均次数；年分析不堆叠折线图与年度逐日热力图，避免为长周期制造预测趋势。
- 200% 字体下，日期选择器的完整日期与星期拆成有意图的两行，避免星期被挤成孤立换行。
- 200% 字体下，确认弹窗标题使用较紧凑的字阶，两个操作改为纵向排列，避免孤字换行和按钮标签截断。

## 系统 UI 边界

- 状态栏、导航栏、软键盘、无障碍服务和底层窗口机制遵循 Android 系统，这是平台行为而不是应用视觉组件。
- 应用可见的弹窗容器、标题、说明、按钮、输入框状态与错误反馈必须使用项目主题；运行时源码不直接使用默认 `AlertDialog` 或 `TextButton`。
- 当前应用没有运行时权限请求，因此不会出现相机、定位、通讯录等系统权限弹窗。

## 记录时间与感受（Issue #105）

- 计数为 0 时保持原有“只记录次数”页面，不显示详情入口；计数为 1 次及以上时，在“已记录 · N 次”和月度摘要之间显示次级按钮“记录时间和感受”。
- 入口按钮显示时钟与对话气泡图标、帮助文案“为这 N 次补充详情”和右箭头，点击前不出现时间字段或文本框。
- 展开后显示“本次详情”和“每增加 1 次，自动新增一条”，按次数渲染“第 1 次”到“第 N 次”的逐次详情行。开始/结束时间字段可点击打开系统时间选择器；“写感受”按行展开多行编辑框。
- 每条详情先显示序号与“第 N 次”，下一行从详情区左边缘排列开始时间、结束时间和“写感受”；标准手机宽度下三个操作同高同轴。未选择时两个时间框分别在框内居中显示“开始时间”和“结束时间”，选择后具体时间仍居中；不重复显示框外“开始/结束”小标签和框内尾部箭头，TalkBack 仍明确区分开始与结束。
- 感受实时显示 `当前 / 100`，按可见 Unicode 字符计数，中文、标点和 emoji 各占 1 个；详情全部可选，保存次数不依赖填写详情。
- 聚合次数仍支持完整非负 `Int` 范围，但详情编辑器最多物化 512 行；超过 512 次时只显示次数编辑，当前次数内的已有详情保留，次数回到边界内后可继续编辑。
- 展开/收起和次数增减都保留未保存草稿；减少带内容的最后一条时先二次确认，减少到 0 会清空详情草稿。底部保存栏保持固定，详情列表随页面滚动。
- 结束时间早于开始时间时显示“结束时间不能早于开始时间”，不允许写入非法时间范围；详情感受不进入日志、诊断或统计。
