# 界面与交互

最后复核：2026-08-02

> 本文描述当前 Compose 运行时已经实现的交互。UI v2 Stage 1 至 Stage 4 已验收，Stage 5 正在进行集成 QA；不能把后续目标图误写成已验收行为。Stage 4 的截图和边界证据见[审计记录](product/audit/2026-08-01-ui-v2-stage4/README.md)，Stage 5 的最终证据见[审计记录](product/audit/2026-08-01-ui-v2-stage5/README.md)。

视觉基线：接近白色的暖中性 Canvas、白色 Surface 和石墨文字。手冲使用克制紫色与飞机符号，做爱使用克制深红与非露骨双环符号；两个模块始终同时显示清晰文字，不能只依赖颜色或图标。

## 导航

底部仅两个入口：

1. 日历
2. 统计

当前不建立设置或“关于”入口，避免为尚未存在的能力增加空导航。

选中入口只使用当前模块色图标、文字和下划线，不使用大面积实心胶囊；整个入口保持至少 48dp 的点击与 TalkBack 范围。

## 共享外壳

- 日历和统计使用同一组 20dp 页面水平边距、排版、分隔线和底部导航。
- “手冲 / 做爱”切换器为单层外框并严格二等分；两个模块各占完整宽度一半和完整高度。
- 选中颜色覆盖对应半区直至外框边界，不存在内部小胶囊；颜色范围、点击范围和语义范围一致。
- 手冲选中使用 `#72517C`，做爱选中使用 `#8D3E45`；白色文字对两者均达到 WCAG AA。
- 统计周期使用文字与 2dp 下划线表达选中，不使用卡片内再套胶囊。
- 正常字号和 200% 字体下，模块切换、周期标签和底部导航均保持可读，点击目标不小于 48dp。

## 日历页

- 日历与统计顶部提供“手冲 / 做爱”模块切换；切换保留浏览日期，重启恢复上次选择。
- 顶部显示年月、上一月、下一月、回到今天；年月标题本身是可点击的 48dp 入口，打开年份与日期选择器。
- 可浏览范围为 1970 年 1 月至当前月；到达边界后对应月份箭头禁用。
- 快速跳转使用应用内原生暖色弹窗，不调用系统日期选择器：先点年月标题打开月历，再点年份标题进入三列年份列表，可一次跳过多年。
- 日期选择器禁止 1970 年以前和今天以后日期；切月会把选中日夹紧到目标月的合法日号，确认后只移动浏览焦点，不误打开记录编辑页。
- 快速跳转和账号同步共用应用内暖中性 Surface、应用级紫色主按钮与 48dp 点击目标；弹窗状态用标题、文案和形状共同表达，不只依赖颜色。
- 年月下方使用紧凑文字摘要，只显示“本月总次数 · 发生天数”；记录日均留在统计页，不再使用大面积摘要胶囊。
- 当前月日期由真实 `YearMonth` 生成并按周一至周日排列，只补空位、不显示相邻月份日期；五周月和六周月按真实行数展开。
- 日期格同时表达今天、选中状态和记录状态。
- 过去未填写：使用浅中性色整格背景，不显示“未填”汉字，并提供“未填写”的 TalkBack 文案。
- 明确 0 次：使用白底、当前模块主色描边和空心圆，不显示 `0次` 汉字，并提供“明确记录当前模块 0 次”的 TalkBack 文案。
- 1、2、3+ 次：使用当前模块同色系由浅到深的整格背景，并显示精确次数；极端值使用 `9+` 视觉缩写，详情仍显示真实值。
- 今天使用当前模块色边界；今天未填写时只额外显示“今”，已经保存记录时保留次数文字并由边界表达今天。
- 未来日期使用比过去未填写更浅的独立禁用中性色，并禁止点击和保存；日期格内不显示“未来”汉字，TalkBack 仍明确未来且不可记录。
- 短月份在底部导航上方使用轻分隔线、“点击日期记录”和集中四态图例收尾；六周月和大字体超出可用高度时自然滚动。图例不是按钮，也不改变点击日期进入记录页的行为。

## 日期记录面板

- 标题为完整日期和“今天/过去日期”辅助说明。
- 中心突出当前次数。
- `-1` 与 `+1` 为主要快捷操作，次数下限为 0。
- 保存 0 次表示当前模块明确没有；“清除记录”只让当前模块恢复未填写。
- 保存或清除后立即返回日历，并同步更新日历与统计。
- 数据库记录尚未读取完成时，次数控件和保存按钮保持禁用，避免把旧记录误覆盖为 0。
- 保存和清除开始前同步锁定操作，快速连点只执行一次；失败时留在当前页面、恢复按钮并显示重试提示。
- 清除记录需要二次确认；修改次数后返回需要确认是否放弃，防止误触造成数据丢失。
- 清除与放弃确认统一使用应用内 Surface 弹窗，不调用 Material 默认 `AlertDialog`；危险操作使用深红实心按钮，取消/继续编辑使用应用级紫色描边按钮。
- 保存或清除失败使用应用内当前模块深色 Snackbar：手冲使用紫色深色阶，做爱使用深红色深色阶，并保留明确文字和 TalkBack 实时提示。

## 统计页

- 顶部周期分段：周、月、年、全部历史；选中周期使用当前模块色文字和下划线。
- 周、月、年提供上一周期、下一周期和标题日期选择器；当前周期不允许继续进入未来。
- 日历与统计共用浏览日期。切换统计周期只改变聚合范围，不重置日期：例如浏览 2026 年 5 月 6 日时，周显示 5 月 4–10 日，月显示 5 月，年显示 2026 年。
- 第一屏固定一个当前模块主指标“总次数”，并在同一张摘要卡中显示发生天数和记录日均；不使用三张等权 KPI 卡。
- 月周期下方显示按当前月份聚合的 5/6 个周次数柱、每周发生天数、活跃周数和峰值周；不重复主页日期网格。年周期下方显示 12 个月次数柱状图、季度次数占比和最高/最低月份摘要；全部历史仍以事实列表为主。
- 下方图表和列表只展示已发生事实：0 次不绘制假柱，未填写不伪装成 0，未来月份不预测。
- 进行中的周期明确标注；未来日期/月不预测。
- 全部历史为空时提供“去日历记录”按钮；统计明细当前只读，不伪装成可点击入口。

## 登录与找回密码

- “忘记密码？”只在登录模式出现，使用登录页已输入邮箱作为预填值；注册模式不显示该入口。
- 登录与注册区域常驻小字说明需要打开 VPN（梯子）；同一提示同时明确“先在本机使用”无需开启，但不会同步云端。
- 找回密码使用暖中性 Surface、应用级紫色描边和应用内弹窗，不使用系统默认确认框。
- 邮箱无效时在输入框内给出文字错误；发送期间锁定输入、取消和发送按钮，避免重复请求。
- 成功状态统一显示“如果该邮箱已注册”，不暴露账号是否存在；同时提醒检查收件箱和垃圾邮件。
- 断网、限频、额度耗尽和其他失败均留在弹窗内并允许重试，不显示 Firebase 内部错误文本。
- 密码重置遇到网络失败时直接提示打开 VPN 后重试。
- 系统字体 200% 时操作纵向排列，标题、说明、输入框和两个操作均保持可见；重置邮件打开的浏览器/邮件客户端属于系统边界。

## 本机诊断

- 未登录时从顶部“诊断”进入；已登录时从“账号与云同步”弹窗进入。
- 诊断弹窗使用应用内纸感组件，允许先检查全文，再复制或调用 Android 系统分享面板。
- 摘要只包含应用版本/构建类型、设备与 Android 版本、同步状态、是否存在待同步、数据库状态/schema 和最近一次净化错误类别。
- 不包含邮箱、UID、任一模块日期、次数、密码、云文档内容、原始异常或生成时间。
- 复制和分享结果在弹窗内给出文字反馈；分享目标选择器属于明确的 Android 系统边界。

## 账号删除

- “删除账号与云端数据”位于账号弹窗底部，使用危险文字层级，不与“退出登录”混淆。
- 第一层弹窗说明不可撤销，并要求选择本机记录处理方式；“保留在本机（推荐）”默认选中，“同时删除本机记录”必须主动选择。
- 第二层弹窗再次说明实际影响并要求当前密码；密码为空时永久删除按钮不可用。
- 删除期间锁定关闭、返回、输入和提交，避免重复请求；失败原因留在弹窗内，密码错误、网络/VPN、限频和登录状态变化使用不同文案。
- 所有警告、选择卡、密码框和危险按钮使用应用内纸感组件；只有软键盘属于系统 UI。

## 无障碍

- 颜色不是唯一状态表达；同时使用数字、形状和文本。
- 云同步因网络失败时显示数秒的应用内当前模块色 Snackbar，手冲使用紫色、做爱使用深红色，明确提示打开 VPN，并说明记录仍已保存在本机；非网络类失败不显示 VPN 提示。
- “账号与云同步”弹窗打开时，网络类 VPN 提示必须移入弹窗内的同步状态卡，根页面 Snackbar 立即消失，避免被模态遮罩压在下层或重复显示。
- 点击目标至少 48dp。
- 支持 TalkBack、系统字体缩放与高对比检查。
- 200% 字体下月份标题改为两行，日期格增高，统计指标卡改为纵向排列，避免文字截断。
- 周/月分布图必须直接标注状态并提供完整 TalkBack 语义；月统计周桶读出周范围、次数和发生天数，年图提供 12 个月、季度和极值摘要的可访问语义。

## 加载、保存与视觉对比度

- 本机数据库首次读取期间只显示明确加载状态，不提前显示假的“0 次 · 0 天”或空日历。
- 已有记录未发生变化时主按钮显示“已保存”并保持禁用；只有次数变化后才变为可操作的“保存记录”，避免无意义写入和云端修订。
- 日历年月与统计周期标题保持整块可点击和 TalkBack 跳转语义，但不显示重复的“点此快速跳转”副标题。
- 手冲主色 `#72517C` 对白色对比度约 6.60:1；做爱主色 `#8D3E45` 对白色约 7.22:1；正文 `#2D2926` 对 Canvas `#FAF8F3` 约 13.58:1。日期状态仍同时使用数字、边框和文案，不只依赖颜色。
- 月历只渲染当前月份的日期；前后月份对应位置留白、不可点击且不进入 TalkBack 焦点。相邻月份通过左右箭头或年月快速跳转进入。
- 周统计使用七日纵向分布卡，直接标注每天次数、日号以及未填写/未来状态；月统计使用 5/6 个周聚合柱、发生天数、活跃周数和峰值周，不再重复主页日期网格；未填写、0、正次数和未来均有不同语义。
- 周/月/年顶部采用单一主摘要卡突出当前模块周期总次数，并并列展示发生天数和记录日均；年分析不堆叠折线图与年度逐日热力图，避免为长周期制造预测趋势。
- 200% 字体下，日期选择器的完整日期与星期拆成有意图的两行，避免星期被挤成孤立换行。
- 200% 字体下，确认弹窗标题使用较紧凑的字阶，两个操作改为纵向排列，避免孤字换行和按钮标签截断。

## 系统 UI 边界

- 状态栏、导航栏、软键盘、无障碍服务和底层窗口机制遵循 Android 系统，这是平台行为而不是应用视觉组件。
- 应用可见的弹窗容器、标题、说明、按钮、输入框状态与错误反馈必须使用项目主题；运行时源码不直接使用默认 `AlertDialog` 或 `TextButton`。
- 当前应用没有运行时权限请求，因此不会出现相机、定位、通讯录等系统权限弹窗。
