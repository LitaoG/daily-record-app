# 双模块统计口径

最后复核：2026-08-01

手冲统计从 `hand_brew_records` 推导，做爱统计从 `sex_records` 推导。两类强类型记录只在 UI 层投影为 `DailyCountEntry`，共用同一套纯计算函数；任何统计调用一次只接收一个模块的数据。

## 指标

```text
totalCount = SUM(moduleCount)
occurredDays = COUNT(DISTINCT localDate WHERE moduleCount > 0)
averagePerRecordedDay = totalCount / occurredDays
```

`occurredDays = 0` 时日均显示 `0.0`。`moduleCount = 0` 的日期保留在明细中，但不增加次数和发生天数。未填写没有数据库行；0 次和未填写都没有柱状高度，但文字必须不同。

## 周期

- 周：星期一 00:00 对应的本地日期至下周一，不跨周期重复。
- 月：月初至下月月初。
- 年：1 月 1 日至下一年 1 月 1 日。
- 全部历史：最早记录日至今天；没有记录时为空状态。

当前未结束周期显示“进行中”。未来日期和未来月份不生成预测值。

周、月、年都由同一个浏览日期 `anchorDate` 决定。切换模块、日历月份或统计周期不会把它重置为今天。模块选择和周期选择是两个独立状态。

## 展示

- 周视图：固定周一到周日，以七日分布卡逐日直接标注次数和日号；过去未填写显示“未填”，明确 0 次显示 `0`，未来日显示“未来”，TalkBack 仍读出完整日期、次数和天数。
- 月视图：按当前 `YearMonth` 生成每一个真实日期的方形热力单元；网格补位不是日期，切换月份必须重新构建日期集合，不保留前一月行或数值。过去未填写、明确 0 次、正次数和未来日期使用不同状态。
- 年分析：固定 12 个月次数柱状图，并列出季度次数占比、最高月份和最低月份；未来月份为空，进行中的月份可以展示已发生事实但不进入极值排名。未填写月份不伪装成 0，明确保存 0 的完整月份可以成为最低月份；没有合格月份或季度总数为 0 时显示空状态。
- 全部历史：按年份汇总当前模块次数和发生天数。

汇总卡、分布图和表格必须使用相同日期范围；明细加总必须等于汇总。分布图只表达已发生事实，不做预测。

## 固定验收数据

手冲回归数据仍使用 2026 年 1–10 月的 128 次、74 天、日均约 1.7；11–12 月为空。做爱统计使用独立数据集验证 0 次、正次数、未来日期和全部周期，不能读取手冲数据。

## 边界测试

空数据、明确 0 次、同日多次修改、1 月 31 日跨月、2 月 29 日、五周月、六周月、月末、12 月末、跨年周、1970 下限、当前周期上限、未来日期、并列极值、进行中月份、季度总量和设备时区变化。
