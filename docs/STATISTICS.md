# 双模块统计口径

最后复核：2026-08-12

自慰统计从 `hand_brew_records` 推导，做爱统计从 `sex_records` 推导。两类强类型记录只在 UI 层投影为 `DailyCountEntry`，共用同一套纯计算函数；任何统计调用一次只接收一个模块的数据。

## 指标

```text
totalCount = SUM(moduleCount)
occurredDays = COUNT(DISTINCT localDate WHERE moduleCount > 0)
averagePerRecordedDay = totalCount / occurredDays
```

`occurredDays = 0` 时日均显示 `0.0`。界面把 `occurredDays` 显示为“发生天数”；`moduleCount = 0` 的日期保留在明细中，但不增加次数和发生天数。未填写没有数据库行；0 次在年度折线中保留基线实心点和数值标签，未填写没有实心点，二者不能混同。

## 周期

- 周：星期一 00:00 对应的本地日期至下周一，不跨周期重复。
- 月：月初至下月月初。
- 年：1 月 1 日至下一年 1 月 1 日。
- 全部历史：最早记录日至今天；没有记录时为空状态。

当前未结束周期显示“进行中”。未来日期和未来月份不生成预测值。

周、月、年都由同一个浏览日期 `anchorDate` 决定。切换模块、日历月份或统计周期不会把它重置为今天。模块选择和周期选择是两个独立状态。

## 展示

- 周视图：固定周一到周日，以七日分布卡逐日直接标注次数和日号；过去未填写显示“未填”，明确 0 次显示 `0`，未来日显示“未来”，TalkBack 仍读出完整日期、次数和天数。图例“未到”复用主页未来日期块的 `Disabled` 背景色，`1 / 2 / 3 / 4次及以上` 逐档复用主页对应次数的块色；手冲、做爱两个模块都保持这套映射。未来环段继续更细并保留虚线，周几日期文字继续使用暗淡的未来字色，作为辅助状态语义。
- 月视图：按当前 `YearMonth` 生成完整逐日序列，但不复刻主页日期网格。每日次数图只为正次数绘制竖线、节点和精确标签；标签贴近节点，避免与图表主体脱节。横轴只显示 1、5、10、15、20、25 和月末日期，这些日期在基线用当前模块色的轻量圆环与圆点高亮，帮助用户把脉冲快速对应到日号；明确 0 次是模块色基线实心点，过去未填写是中性空心点，未来日期是更淡的禁用空心点。次数分布只以已填写日期为分母，分为 `0 / 1 / 2 / 3 次以上` 四档，未填写和未来日期在分母外单列。单日极值只显示最高单日和最低单日次数，不展开日期列表；最低单日不统计 0、未填写或未来。切换月份必须整体重算日序列、分布和极值。
- 年分析：固定 12 个月直线折线面积图，并列出季度次数占比、最高月份和最低月份。相邻有效月份以直线连接，不使用曲线插值。每月都保留横轴位置；已记录月份显示实心点和次数，明确 0 次落在基线，未填写或未来月份只显示空心位置标记且不参与连线。进入年度统计或切换年度数据时，真实折线、面积、实心节点和次数标签用约 1.6 秒从左向右揭示一次，结束后保持静止且不循环；坐标轴、网格、月份和空心状态点始终稳定显示。未来月份为空，进行中的月份可以展示已发生事实但不进入极值排名；没有合格月份或季度总数为 0 时显示空状态。年视图“月均”的分母为“已度过月份数”（当前年含进行中的当月，过去年恒为 12），口径与“全部历史”的日均（总次数 ÷ 发生天数）不同。
- 全部历史：按年份汇总当前模块次数和记录天数；顶部只显示覆盖的年月范围，不再重复展示“记录起点”或“首次记录”。

汇总卡、分布图和表格必须使用相同日期范围；明细加总必须等于汇总。分布图只表达已发生事实，不做预测。

## 固定验收数据

自慰回归数据仍使用 2026 年 1–10 月的 128 次、74 天、日均约 1.7；11–12 月为空。做爱统计使用独立数据集验证 0 次、正次数、未来日期和全部周期，不能读取自慰数据。

## 边界测试

空数据、明确 0 次、同日多次修改、1 月 31 日跨月、2 月 29 日、28/29/30/31 天月份、月末、12 月末、跨年周、1970 下限、当前周期上限、未来日期、并列日/月极值、进行中月份、季度总量和设备时区变化。
