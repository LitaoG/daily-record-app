# 手冲日历 v1.0.0-beta.1

这是面向本人和少量朋友的首个 GitHub Release 候选版。

## 本版包含

- 只记录每天手冲次数的月历，支持历史年月快速跳转。
- 明确区分未填写、0 次和正次数。
- 周、月、年和全部历史统计。
- Room 本地优先存储，无网络也能记录和查看。
- 可选邮箱密码账号、跨设备恢复、密码重置和差异化同步错误提示。
- 可复制、可分享且不含记录内容的本机诊断摘要。
- 应用内二次确认的账号与云端数据永久删除；本机记录默认保留。

## 安装与升级

1. 只从本仓库 GitHub Releases 下载 `hand-brew-calendar-v1.0.0-beta.1.apk`。
2. 按同页 `.sha256` 文件校验 APK。
3. Android 可能要求允许浏览器或文件管理器“安装未知应用”。
4. 首次从 Android Studio Debug 版切换时不能直接覆盖。请先确认账号已同步，再卸载 Debug 版并安装此 APK；只保存在 Debug 本机空间的数据不会自动迁移。
5. 从本版开始，后续 GitHub Release 使用同一签名证书，可覆盖安装并保留 Room 数据。

## 已知限制

- 中国大陆普通网络可能无法访问 Firebase；本机记录不受影响，登录、密码重置和云同步通常需要 VPN（梯子）。
- 密码重置由 Firebase 托管页面完成，邮件会打开浏览器。
- App Check 尚未强制，避免未经验证的侧载完整性配置阻断全部用户。
- 当前仅支持 Android 8.0（API 26）及以上。

## 数据与隐私

- 核心记录先保存在设备 Room 数据库。
- 只有用户选择注册/登录后，记录才同步到该 Firebase 账号。
- 应用不含广告、社交、短信验证码或其他活动记录。
- 账号弹窗可永久删除账号与本人云端记录，并明确选择是否保留本机记录。
- 详情见仓库根目录 `PRIVACY.md`。
