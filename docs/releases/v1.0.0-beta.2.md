# 私密日历 v1.0.0-beta.2

状态：`historical release note — immutable`

这是面向本人和少量朋友的第二次 GitHub Release 候选版。它在保留本地优先和双模块独立数据边界的前提下，完成了统计页与历史跳转的收口。

## 本版包含

- 自慰与做爱两个独立记录模块；同一天可以分别记录两类次数。
- 月统计改为逐日次数脉冲图、次数分布和单日极值摘要，不再重复主页日历。
- 年统计使用 12 个月直线折线面积图，进入年度页时从左到右播放一次。
- 周、月、年、全部周期切换和年月选择器保持当前浏览范围，不混入其他模块数据。
- 统一未来日期、未填写、0 次和正次数的颜色与无障碍语义；同步/诊断文案集中维护。
- 本地 Room、可选邮箱密码账号、Firebase 云同步和离线记录行为保持不变。

## 安装与升级

1. 只从本仓库 GitHub Releases 下载 `hand-brew-calendar-v1.0.0-beta.2.apk`。
2. 按同页 `.sha256` 文件校验 APK。
3. Android 可能要求允许浏览器或文件管理器“安装未知应用”。
4. `versionCode=3` 沿用 beta.1 的稳定 release 证书，可覆盖安装并保留 Room 数据。
5. 首次从 Android Studio Debug 版切换时不能直接覆盖；请先确认账号已同步，再卸载 Debug 版并安装此 APK。

- 公共 `main`：PR #67 squash 合并后的提交。
- 最终设备套件：93 项执行、1 项按设计跳过、0 项失败；Auth/Firestore 使用隔离模拟器。

## 已知限制

- 中国大陆普通网络可能无法访问 Firebase；登录、密码重置和云同步通常需要 VPN（梯子）。
- 密码重置由 Firebase 托管页面完成，邮件会打开浏览器。
- App Check 尚未强制，避免未经验证的侧载完整性配置阻断用户。
- 当前仅支持 Android 8.0（API 26）及以上。

## 数据与隐私

- 核心记录先保存在设备 Room 数据库。
- 只有用户选择注册/登录后，记录才同步到对应 Firebase 账号。
- 应用不含广告、社交、短信验证码或其他活动记录。
- 账号弹窗可永久删除账号与本人云端记录，并明确选择是否保留本机记录。
- 详情见仓库根目录 `PRIVACY.md`。
