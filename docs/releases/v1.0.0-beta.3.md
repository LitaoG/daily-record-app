# 私密日志 v1.0.0-beta.3

这是第三次 GitHub Release 候选版，基于公共 `main` 的安全、性能、生命周期与文档审计修复发布。它继续面向本人和少量使用者提供签名 APK，不代表已经面向应用商店或大规模公开发布。

## 本版本包含

- 云端记录写入统一通过 trusted callable，并对详情条目逐项校验；详情总数限制为 1000 条，客户端编辑器最多物化 512 行，避免不可信次数造成过量内存分配。
- 账号删除、普通记录清除、同步闸门和 Room 合并流程加强，避免竞态写回、重复查询和跨账号数据残留。
- 日期/时间滚轮、详情编辑、TalkBack 语义、错误码和输入框颜色构造收敛为共享实现，减少重复逻辑和生命周期风险。
- Release 证书指纹、版本/tag 匹配、Functions 依赖安装、文档完整性和 Firestore Rules 校验纳入 CI 门禁。

## 安装与升级

1. 从本仓库 [GitHub Releases](https://github.com/LitaoG/daily-record-app/releases) 下载 `hand-brew-calendar-v1.0.0-beta.3.apk` 与同名 `.sha256`。
2. 用 `.sha256` 文件校验 APK；正式 APK 必须使用稳定 release 证书签名。
3. 从 `v1.0.0-beta.2` 升级时，`versionCode` 从 3 增至 4，使用同一份 release keystore，可覆盖安装并保留 Room 数据。
4. Debug APK 使用不同证书；首次从 Debug 切换前请先确认云端已同步，再卸载 Debug 版并安装本 Release。

## 已知限制

- 当前仅支持 Android 8.0（API 26）及以上。
- Firebase 登录、密码重置和云同步在部分网络环境中可能需要 VPN；本机记录和离线使用不依赖 Firebase。
- App Check 尚未强制启用，当前仍通过 GitHub Releases 分发。

## 验证

- 版本元数据、文档、复制完整性和 Firestore Rules 校验由发布工作流执行。
- JVM 测试、Lint、Release 构建、稳定证书指纹校验和 SHA-256 生成均由 GitHub Actions 执行。
