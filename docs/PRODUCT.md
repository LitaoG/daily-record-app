# 产品契约：私密日历

状态：`v1.0.0-beta.2` 当前产品契约（P0 已实现）
最后更新：2026-08-08

## 产品目的

让用户在几秒内分别记录“某天手冲了几次”和“某天做爱了几次”，并能可信地回看每个模块的日历与周、月、年、全部历史统计。

产品只有两个固定、独立的记录对象：手冲和做爱。界面提供模块切换，但没有活动管理、任意自定义活动或合并总次数。

当前通过 GitHub Releases 向本人和少量使用者提供签名 APK；日常反馈用于继续修复问题，不代表已经面向应用商店或大规模公开发布。

## P0 用户任务

1. 打开应用查看当前月历。
2. 选择手冲或做爱模块；切换模块不改变当前浏览日期和统计周期。
3. 点击日期，使用 `+1`、`-1` 调整并保存当前模块次数。
4. 把次数设为 `0`，明确表示当天没有发生当前模块行为。
5. 清除当前模块记录，让该模块日期回到“尚未填写”，不影响另一模块。
6. 查看当前模块周、月、年和全部历史的次数、天数、日均与精确明细。
7. 点击年月标题直接选择历史年份和日期，不需要逐月点击箭头。
8. 可先完全离线使用，也可用邮箱和密码注册/登录，把两个模块的本机记录合并到账号。
9. 在另一台手机登录同一账号，恢复两个模块的日历与统计数据。
10. 忘记密码时，通过注册邮箱接收 Firebase 密码重置链接，再返回应用登录。

## 业务规则

- 每个模块、每个本地日期最多一条记录；同一天可以同时存在两类记录。
- 次数只接受非负整数。
- `count > 0`：当前模块发生过。
- `count = 0`：当天没有发生当前模块行为，但用户已明确填写 0。
- 没有数据库行：尚未填写。
- 总次数是范围内 `count` 之和。
- 发生天数只统计当前模块中 `count > 0` 的不同日期。
- 记录日均 = 当前模块总次数 / 当前模块发生天数；没有发生天数时显示 `0.0`。
- 两个模块的统计永不相加或互相读取。
- 未来日期默认不可记录；历史日期可编辑。
- 日历支持 1970 年 1 月 1 日至今天，最早月份继续向前的导航禁用。
- 月历网格只显示当前月份日期；前后月份位置留白，切月使用箭头或年月标题快速跳转。
- 日历和统计共享同一个“浏览日期”；模块切换、页面切换与周/月/年切换都不会重置浏览日期。
- 上次选择的模块持久化，应用重启后恢复。
- 所有保存先落本地数据库，界面立即更新。
- 未登录时记录属于本机空间；首次登录时，本机记录与账号数据按日期安全合并。
- 登录不是使用核心记录功能的前置条件，普通登录不使用短信或验证码。
- 登录与注册提示需要打开 VPN（梯子）；本机使用无需开启，但不提供云端同步与换机恢复。
- 登录、注册和手动同步的交互等待最多约 5 秒；Firebase 不可达时必须停止等待并显示网络/VPN 提示，不能误报邮箱或密码错误。
- 密码重置入口只在登录模式显示；无论邮箱是否存在都使用同一成功文案，不能泄露账号注册状态。
- 用户明确选择本机模式后，冷启动仍直接进入本机记录；点击“登录并同步”才返回登录页。
- 同一账号多设备冲突按本地保存的云端修订基线处理；基线落后时保留服务器版本，设备时间不决定覆盖结果。
- 清除记录使用同步墓碑，不能因另一台离线设备恢复而“复活”。
- 周明细中的“未填写”和明确 `0` 次必须保持可区分。

## 主界面

- 日历：默认入口，查看当前模块每一天的状态和次数。
- 统计：查看周、月、年和全部历史汇总及明细。
- 日期记录面板：从日历进入，不作为第三个主导航。

## 明确不做

伴侣身份、具体时间、地点、时长、姿势、备注、图片、避孕、经期、医疗建议，以及健身、喝水、学习、睡眠、跑步、自定义活动、活动管理、目标、连续打卡、提醒、社交、排行榜、短信验证码登录、订阅、广告和 iOS/Web 客户端均不属于当前产品。未来新增类型必须单独立项和建模，不能把现有两个模型改造成万能活动表。

## P0 验收

- 飞行模式下可新增、修改、清除记录，重启后仍存在。
- 同一模块同一天重复保存只更新同一条记录；保存或清除一个模块不影响另一个模块。
- `0` 与未填写在数据库、视觉和 TalkBack 语义上不同。
- 手冲固定数据集正确得到 128 次、74 天、日均约 1.7；做爱模块使用独立固定数据集验证。
- 周/月/年/全部历史的汇总与明细加总一致。
- 跳转历史日期后，周统计取该日期所在的自然周，月统计取该日期所在月，年统计取该日期所在年。
- 闰年、月末、跨年周和空数据不崩溃、不伪造数据。
- 月份变化后逐日序列、次数分布和单日极值只统计新月份，不保留上个月日期或数值。
- 断网编辑显示待同步，恢复网络后自动上传；进程重启后待同步数据仍存在。
- 瞬时监听错误会自动重连，恢复后继续接收其他设备的更新。
- 新设备登录同一账号可以恢复新增、修改和清除；不同账号不能互相读取。
- 找回密码覆盖邮箱预填与校验、发送中锁定、统一成功提示、断网、限频、额度耗尽和失败重试。
- 登录后即使 Firestore 暂时不可达，本机记录也必须先出现在账号空间；Firebase 恢复可达后自动冲刷待同步记录。
- 同步失败必须区分网络、认证、权限、配额、服务、数据和未知错误；只有网络错误提示检查 VPN，其他错误显示对应说明与可执行操作。
- 删除账号必须经过警告页和密码重验，先删除本人两个云端集合再删除认证账号；本机两个模块默认保留为离线记录，只有用户明确选择时才删除。
- Room v1→v4、v2→v4、v3→v4 迁移均不丢原手冲记录；v4 新表初始为空。
